# 1주년 미션 (오프라인 PWA)

순수 HTML/JS/CSS. 빌드 없음. 수정은 거의 `stages.js`만.

## 정답 해시 만들기
`tools/hash.html` 열고 정답 입력 → 해시 복사 → `stages.js`의 `answerHash`에 붙여넣기. (trim + 소문자 기준)

## 로컬 테스트
- VS Code Live Server로 `index.html` 열기 (localhost는 SW/카메라 허용).
- 폰 테스트는 HTTPS 필요 → Cloudflare Pages에 배포해서 확인하는 게 가장 편함.
- 디버그: `#stage=5` 해당 스테이지로 점프, `#reset` 진행 초기화.

## Cloudflare Pages 배포
1. 이 폴더를 Git 저장소로 올리고 Cloudflare Pages에서 연결 (또는 Direct Upload로 폴더 드래그).
2. 빌드 명령 없음, 출력 디렉터리는 루트(`/`).
3. 파일 수정 후 재배포할 땐 `sw.js`의 `CACHE` 버전(`anniv-v1` → `v2`)을 반드시 올릴 것.

## 비행기 모드 체크리스트
- [ ] 인터넷 연결 상태에서 열고 우측 상단 "✔ 오프라인 준비 완료" 확인
- [ ] (iPhone) 공유 → 홈 화면에 추가 / (Android) 앱 설치
- [ ] 비행기 모드 ON → 앱 완전히 종료 후 다시 실행 → 정상 로드
- [ ] 입력 퍼즐 정답/오답, 힌트 버튼 동작
- [ ] 새로고침/재실행 후 진행 상황 유지
- [ ] 옥상 AR: 카메라·방향 센서 권한, 목표 방향에서 오브젝트 표시 (GPS 사용 시 비행기 모드여도 GPS는 동작하나 기기에 따라 느림)
- [ ] 테스트 끝나면 `#reset`으로 초기화

## AR 보정 팁
`stages.js`의 `ar.showHeading: true`로 현장에서 현재 방향 각도를 보고 `heading`을 정한 뒤 `false`로 바꾸세요. 센서가 안 되면 "수동 진행" 버튼이 나옵니다.

## QR 코드 (앱 안에서 스캔)
스캔 스테이지는 QR 안의 **글자**를 해시로 비교합니다. 무료 QR 생성기에서 "텍스트" 타입으로 아래 글자를 넣어 만드세요. (대소문자 무관)

| 위치 | QR 글자 (샘플) | stages.js |
|---|---|---|
| 식탁 | `memory-01` | 1번 |
| 스토리지 | `memory-02` | 3번 |
| 우편함 | `memory-03` | 5번 |
| 트렁크 | `memory-04` | 7번 |
| 본넷 | `memory-05` | 9번 |

실제 글자를 바꾸면 `tools/hash.html`로 해시를 만들어 `answerHash`에 넣으세요. 침대 쪽지 QR은 이 앱의 주소(URL)를 넣으면 됩니다. 지하에서 카메라가 안 되면 "코드 직접 입력"으로 넘어갈 수 있습니다.

## 테스트 패널
주소 끝에 `#debug`를 붙여 한 번 열면 우측 하단에 🛠 버튼이 생깁니다(기기에 저장됨). 스테이지 이동 / 현재 스테이지 통과 / 힌트 전부 열기 / 진행 초기화 / 캐시·SW 삭제 / 디버그 끄기. **당일 건네기 전에 `#debug=off`로 꼭 끄세요.**
